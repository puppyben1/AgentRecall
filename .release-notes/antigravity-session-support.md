# 支持 Google Antigravity 会话

<!-- release-target: both -->

## 新增功能

- ✨ 新增可选来源 Antigravity：在 **设置 → 可选来源** 开启后，可以只读方式索引本机 Antigravity 桌面版的会话，搜索并查看用户提问、模型回复与思考过程、工具调用及结果、上下文压缩标记和代理间消息。
- Antigravity 会话会显示所属项目路径和分支，方便按工作区分组和检索。
- Antigravity 会话显示逐次模型调用的 token 用量（输入、缓存、输出与思考），并补出失败或中止的工具调用结果及其错误信息，时间线上不再出现悬空的工具调用。
- 会话标题优先使用 Antigravity 自己生成的标题，没有时才回退到首个提问。
- 同时索引官方 Antigravity CLI（`agy`）的终端会话，并在 **设置 → 可选来源** 中单列开关；CLI 会话的逐次 token 用量与其保留的失败步骤一并展示。
- 子代理会话按父子关系归属到派生它的会话，不再占用顶层列表。
